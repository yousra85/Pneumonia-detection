# Pneumonia Detection Using Deep Learning

This project explores the use of deep learning for medical image classification, aiming to distinguish between normal and pneumonia-affected chest X-ray images.

Using TensorFlow and Keras, the project covers image preprocessing, dataset preparation, CNN-based model development, and model evaluation. It also addresses class distribution and the importance of properly separating training, validation, and test datasets to help prevent data leakage.

**Technologies:** Python, TensorFlow, Keras, NumPy, Matplotlib.

**Objective:** Explore how convolutional neural networks can be applied to medical image analysis and automated pneumonia detection.
